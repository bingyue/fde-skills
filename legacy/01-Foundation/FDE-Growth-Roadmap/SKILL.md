# FDE Growth Roadmap

当用户提出以下问题时使用本 Skill：

- 是否适合做 FDE，如何从研发/产品/咨询/售前迁移；
- 如何准备 FDE 求职：JD 解码、简历、作品集、面试与 Offer 决策；
- 为什么项目不少却晋升停滞，如何补齐影响力证据；
- 是否继续深耕 FDE，还是转向平台、产品或管理；
- 遇到高压、边界混乱、倦怠等职业困境，如何先止损再决策。

## How To Use

1. 先阅读 `README.md`，确定本轮主模式（入行/求职/晋升/生涯设计/职场困境）。
2. 使用 `prompt.md` 运行对应模式，不要一次并行处理多个主问题。
3. 使用 `checklist.md` 校验输入材料、实验动作和复盘节奏。
4. 使用 `evaluation.md` 评分（目标 ≥80/100 且无红线项）。
5. 参考 `workflow.md` 确保输出走完“诊断→实验→证据→复盘”闭环。
6. 需要案例和理论支撑时，加载 `examples.md` 与 `references.md`。

## Output Expectations

输出应至少包含：

- 问题重述与模式判断（事实/推断/待验证项分离）；
- GROWTH 结果：价值约束、岗位现实、三路径、实验设计；
- 证据资产：JD 证据矩阵、项目案例卡、作品集索引、求职漏斗；
- 30/60/90 行动计划与止损条件；
- 风险说明：不承诺 Offer、薪资或晋升结果。

如果信息不足，先输出“待确认清单”，不要编造用户背景或市场数据。
