# Roadmap

| Phase | Scope | Current evidence | Next milestone |
| --- | --- | --- | --- |
| Phase 1 — 50+ Core Skills | Standard contracts and enterprise delivery coverage | 60 authored Skills, templates, examples, Schema and validation | Independent field reviews and multilingual editorial review |
| Phase 2 — Industry Skill Packs | Additive industry knowledge, constraints, metrics, terms and cases | Five initial packs and executable composition | Customer-validated benchmarks and versioned professional policy references |
| Phase 3 — Codex / Claude / Cursor / OpenCode Adapters | One Skill source, native generated outputs | Four directory profiles, compiler and format/overwrite tests | Recorded smoke runs in current agent client versions |
| Phase 4 — FDE Blueprint Integration | Compose delivery stages into reproducible project blueprints | Case manifests demonstrate the intended stage contract | Stable blueprint schema, artifact lineage and resumable execution |
| Phase 5 — Skill Registry / Marketplace | Discovery, versioning and ecosystem distribution | Deterministic searchable skills.json with hashes and metadata | Signed version manifests, provenance verification, compatibility search and community review |

The registry is a local index today, not a hosted marketplace. Blueprints are a planned interface, not an implemented autonomous orchestrator. Prioritize simple components, stable contracts and evidence of enterprise usefulness.
